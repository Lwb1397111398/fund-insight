# 博主排名翻转检查（命中率 vs 加权评分）

- 盘点日：2026-07-29
- 口径：存活 `is_correct` 命中率 vs 物化 `accuracy_rate`（加权评分）
- 样本：`is_active` 且至少 1 条已验证结论的博主 **17** 人

## 结论

| 项 | 值 |
| --- | ---: |
| 名次变化人数 | **16 / 17** |
| 名次不变 | 1 |
| 最大名次跃升 | +7（加权第 12 → 命中第 5） |
| 最大名次下滑 | −8（加权第 3 → 命中第 11） |

**用加权评分做「战绩加权」会与命中率主指标系统性错位。**
