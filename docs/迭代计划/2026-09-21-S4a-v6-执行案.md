## 一、判据（全部基金域自证，零 LLM，零股票域探测）

**数据源（离线优先，搜索只做确认）**
- 名册 `http://fund.eastmoney.com/js/fundcode_search.js`：1 请求、3,170,442 B、27,879 条 `码→官方名+类型`；同时建 **名字→码 的倒排索引**（实测 id 60 的正确码 021252 靠名册零请求即可解析）。名册缺失 ≠ 不是基金（实测缺 000938/002154/002261/004529，这些都能由单码接口解析），所以缺失时回落单码，且**永不把"名册查不到"当负证据**。
- 单码 `pingzhongdata/{code}.js` 的 `fS_name`。
- 搜索 `fundsuggest`：payload 自带 `CATEGORYDESC`（`基金`/`深市`/`沪市`/`京市`/`美股`/`港股`/`高端理财`/`债券`），这是**基金/股票定性的唯一可用证据源**；`search_fund` 现在把它丢了。

**归一（先钉死，再谈阈值）**
`unicodedata.normalize('NFKC', …)` + 去空白与全角标点。评审员对 id 25 实测 j=0.467、计划原写 0.4375，差异全在归一细节 → **落一个归一化黄金样例文件**（京东方Ａ／报 喜 鸟／5GETF／华宝中证医疗ETF↔医疗ETF华宝／永赢国证商用卫星通信产业ETF），单测逐项钉死，阈值不再靠口头。

**verdict 判定顺序（顺序即安全，错一步全部股票变 ok）**
1. `F` = 名册[code] 或单码 fS_name；`j = jaccard(NFKC(stored), NFKC(F))`（字符集 Jaccard，语序无关）。
2. **先过域过滤再看自命中**：取 `search(stored)` 中 **NFKC 精确同名** 的命中，若其 `CATEGORYDESC ∈ {深市,沪市,京市,美股,港股}` → `not_a_fund`（硬拒）。实测 10 只股票行的搜索命中码**恰好等于本行码**（德明利→001309），若先看"自命中即 ok"就会全部漏网。
3. `j >= 0.35` → `ok`（含 id 147 j=1.0、id 25 j≈0.47）。
4. `j < 0.35` 且 **板块核心词含非空 CJK** 且 板块核心词与 `F` 的 CJK 字符**交集为空** → **`code_is_other_fund`**（本行码确实是某只基金，但与板块毫无关系：核聚变 vs 机械ETF富国、中药 vs 长盛盛通纯债C）→ 硬拒；目标码可选（先用名册名字倒排解析，解析不到就只标不猜）。非空 CJK 核心词这一条同时保护 id 51（"5GETF"/"6G" 无中文核心词，不进此桶）。
5. 其余 `j<0.35`：用名册名字倒排（离线）找 stored 的基金，命中码≠本行码 → `wrong_code`（给建议码）；`CATEGORYDESC ∈ {高端理财,债券,...}` 等既非证券也非公开基金 → `not_fetchable`（不等同 not_a_fund）；都定不了 → `unknown`（**永不降级**）。
6. 站点负证据按**字节**判：404 页是 HTTP 200 + 3,924 B + 乱码 title，`'页面未找到' in r.text` 永不匹配（会静默退回 v4 的 bug）→ 判据写成 `b'fS_name' not in r.content and b'\xe9\xa1\xb5\xe6\x9c\xaa' in r.content`；异常/超时才是 `probe_unavailable`。
7. **`is_fetchable` 语义重定义为"可服务"** = 能抓到净值 **且** verdict ∉ {not_a_fund, code_is_other_fund, wrong_code}。新鲜度（FSRQ 距今、run-max 相对窗口 10 天）**只写进 evidence，不参与门禁**——否则 QDII（id 1/6/78=006105、109/110）这类"正确但更新慢"的行会被无声踢出服务。
8. **相关性旗标（只报告）**：判据 = 板块核心词与该码官方名 CJK 零交集，**且**存在某只基金官方名逐字包含该板块核心词（说明"本可以配对的场内 ETF 确实存在"）。实测 145 行命中 **8 行**（含 133/134/135/136/140/137/144 + 1 条低置信 121），恰好覆盖老板点名的"十万八千里"（id 34 债市 因无别名/静态来源而漏，属已知局限）。v5 的"逐字包含"单一判据会误报 102/145，不可用。`SectorAlias` 表实测 0 行、`SECTOR_ALIASES` 只有口语→标准名，救不了这些板块 → 别名为空这一事实写进报告。
