## 一、判据（确定性）

**基金域名册**：`http://fund.eastmoney.com/js/fundcode_search.js` —— 1 个请求、3.17MB、27879 条 `码→官方名+类型`，与 `fS_name` 一致。名册**缺失**不等于不是基金（实测缺 000938/002154/603758），所以缺失时回落到单码 `pingzhongdata`；但"站点回答=页面未找到 HTML 签名"是确定的负证据。整轮只需 1 次名册请求 + 少量单码回落，替代 v4 的 105 次（≈26MB）。

对每行（`stored`=fund_name，`code`=fund_code）：
1. 归一：`unicodedata.normalize('NFKC', …)` + 去空白/全角标点（`报 喜 鸟`、`京东方Ａ` 必须能比）。
2. `F` = 名册[code] 或 pingzhongdata[code]；`j = jaccard(NFKC(stored), NFKC(F))`（字符集，语序无关；实测同基金别名 0.583~0.778，股票 vs 无关基金 0.0）。
3. `j >= 0.35` → **`ok`**（含 id 25 SpaceX→159206 j=0.4375、id 147 债券→512000 j=1.0）。
4. `j < 0.35` → 查归属：`search(stored)`（契约已修）过滤 `CATEGORYDESC=='基金'` 且 **命中名 j>=0.6**：
   - 命中码 == 本行码 → `ok`（别名）；
   - 命中码 != 本行码 且本行码**不是**基金域任何品种 → `wrong_code`（给建议码）；
   - 无合格命中，且**存名精确等于某只股票名**（名册/单码均无该名字，且 5GETF 式自我命中不成立）→ `not_a_fund`；
   - 都不成立 → `unknown`（**永不降级**）。
5. 新鲜度：`is_fetchable = 能抓到 且 (行内最新日期 >= 本轮所有行的 run-max FSRQ - 10 天)`。**不用绝对"距今 15 天"**（QDII 实测滞后至 4 天、本地板库最新只到 2026-09-13，用绝对值会整批误判 stale），且**日期取站点值不取本地镜像**。停复牌实测分离度 1d vs 1034d，10 天窗口足够。
6. **相关性旗标（新增，独立于身份）**：`relevance = 板块核心词是否被包含在基金官方名里`（中文板块 Jaccard 全都 ≤0.36，所以**只有"逐字包含 + 别名表"能用**，数值阈值是死代码）。`low` 者**只标注、只报告，不降级**（判相关性需要 LLM，硬判会误杀）。它是 §四 交给 S4b 的排序依据，也是给老板看的那张"十万八千里"清单。
