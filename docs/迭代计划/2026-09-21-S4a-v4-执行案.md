# S4a-v4 执行案：映射表身份体检（基金域自证，零 LLM、零股票域探测）

日期：2026-09-21 ｜ 评分史：v1=62 → v2=68 → v3=66 ｜ **本版取代 v1/v2/v3**
写入范围：仅 `sector_fund_mapping`（本地镜像 `data/fund_insight.db`）。预测零改动，改标在 S4b。

## 〇、v3 被打回的三处，本版换成实测可用的手段

| v3 的错误假设 | 实测（本机、本轮） | v4 的手段 |
| --- | --- | --- |
| 股票域探测可用来判"这是股票" | `push2.eastmoney.com` 在本机 **ProxyError/非 JSON**，永远拿不到结果 → `kind='stock'` 恒为 0，"降为 0 条"这个指标会因为工具坏掉而空过 | **完全不碰股票域**。只用基金域自证：码→真名、名→是不是基金 |
| `official_name` 代表基金域 | 它来自 `search_fund`，而 search 是**混合证券搜索**：`000938`→紫光股份、`液冷`→冰山冷热/五 粮 液 都混在里面 | 权威名改用 `http://fund.eastmoney.com/pingzhongdata/{code}.js` 的 `fS_name`（纯基金域）。实测：000725→"大成添利宝货币B"、000938→"华商稳固添利债券C"、512170→"医疗ETF华宝"、006105→"宏利印度股票(QDII)A" |
| 用二字 Dice 判"名字对不对得上" | 同一只基金的正名/别名语序不同：`华宝中证医疗ETF` vs `医疗ETF华宝` Dice=0.33 → **会把好行判成错行** | 判"是不是同一只基金"改用 **NFKC 归一 + 字符集 Jaccard**（语序无关）。实测分离度极好：同一只基金 0.583~0.778，股票 vs 无关基金 **0.0** |

`unicodedata.normalize('NFKC','京东方Ａ')='京东方A'`（全角 Ａ 必须折半角，否则永远比不上）。

**基金/股票定性（老板的硬要求）怎么在基金域内做到**：search 的 payload 自带域标签——`CATEGORYDESC`+`FundBaseInfo`。实测：`紫光股份→('000938','深市',False)`、`京东方Ａ→深市`、`宏利印度股票(QDII)A→('006105','基金',True)`、`医疗ETF华宝→基金`。所以"名字在任何基金里都找不到"是**可判定的**，不需要股票域，也不会误伤 QDII。

## 一、判定规则（确定性，写进 `fund_api`）

对每行映射（`stored = fund_name`, `code = fund_code`）：
1. `F = fS_name(code)`（基金域权威名）。取不到 → `probe_unavailable`（**永不降级**）。
2. `j = jaccard(NFKC(stored), NFKC(F))`。`j >= 0.35` → `ok`。
3. `j < 0.35` 时查名字归属：`search(stored)` 过滤 `CATEGORYDESC=='基金'`：
   - 命中且码不同 → **`wrong_code`**（存的不是这个码的基金，但名字确实是一只真基金）→ 建议改用命中码；
   - 无任何基金命中 → **`not_a_fund`**（名字根本不是基金：股票/杂词）→ 硬拒；
   - 命中且码相同但字序差异大到 j<0.35 → `ok`（别名，只补 `fund_name`）。
4. `identity_mismatch` 这个名字 v3 里"探测失败也会撞上"的歧义取消，统一拆成 `wrong_code` / `not_a_fund`，两者都有**可解释的一句话中文理由**和（如可能）**建议纠正码**。
5. 短期/停牌识别：`is_fetchable = ok and (nav_date 或 history 末次日期 距今 <= 15 天)`。`history_count>=5` **不再单独作为可用依据**（实测 000938 的历史停在 2020-07 也能过 strict）。停通行记 `stale`，不降级、只标注。
6. 短名防误伤：`len(NFKC(stored)) < 4`（如"京A""紫紫""老登"）时**不降级**，只记 `too_short_to_judge`。

## 二、品种纯度（老板：ETF 最纯粹）

- `场内ETF = 码段 ^(15\d{4}|5\d{5})$ 且名含 ETF`；`feeder = 名含"联接"`（**先于 etf/lof 判**，162412 名字含 ETF 且码落 16\d{4}）；`exchange_other = 场内码段但名不含 ETF`；再 lof / otc。
- `KIND_PRIOR`：etf 1.0 / exchange_other 0.8 / lof 0.7 / feeder 0.45 / otc 0.4 / unknown 0.3。**不设 `KIND_PRIOR['stock']`**（离线判不到域名，留了就是死代码）。
- `SectorDecision.etf_exhausted`（放决策层，不放候选层）：确定性搜段确认"该板块无场内 ETF"时置真；`auto_reviewable` 追加"非 etf 且非 etf_exhausted → False"。S4a 期间 agent 拿不到 LLM，这条主要是**为 S4b 备好门禁**，不当作本轮成果。

## 六、v3 的 10 条 MUST-FIX 处置

1 名字源不是基金域 → §〇/步骤1；2 股票探测不可达且指标空过 → 全链路放弃股票域（步骤 9③）+ 成功率断言；3 只在该仲裁的地方仲裁 → verdict 只在两边名字都取到时才判（步骤 2）；4 阈值/归一 → NFKC + Jaccard + 短名豁免（§一.6）；5 `history_count` 不代表新鲜 → `nav_date<=15d`（§一.5）；6 爆炸半径重复计数 → 互斥分桶 + 24 上限（步骤 8）；7 幂等定义 → 三元组（步骤 7）；8 top-1 无下限会瞎给 → 0.5 下限/逐字命中 + 债券QDII豁免 + FK 落库（步骤 13/14）；9 老板看不到结果 → 接口+UI 徽标与筛选（步骤 11）；10 加列等于改结构 → **零新列、零迁移**（步骤 4）。
