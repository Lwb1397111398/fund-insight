# Step 3 候选：提升正确率（命中率）杠杆清单

主指标已钉死：**存活命中率**（见 `docs/ACCURACY_METRIC_SPEC.md`）。  
以下为候选杠杆，**未实施**，供下一步挑选。

| # | 杠杆 | 作用点 | 风险/依赖 |
| --- | --- | --- | --- |
| L1 | **按命中率（非加权分）加权博主**进建议证据 | `advice_evidence` 选博主/权重 | 小样本虚高 → 需 min_n（如 ≥5/≥10） |
| L2 | **降权/排除低命中博主** | 证据包 caps | 可能证据变空 → 与 P1 fail-closed 联动 |
| L3 | **方向可验证性门槛**（模糊方向进 other 不进分母） | 验证/分析 | triage 已有 other 桶？需核对是否进 is_correct |
| L4 | **板块/周期分层命中率** | 展示与加权 | 样本更碎 |
| L5 | **近期窗口命中率**（如 90 天）vs 生涯 | 排行/加权 | 与挂起的 180 天双口径相关 |
| L6 | **验证质量**（净值就绪、不早验） | 已做边界 | 减少脏结论污染分母 |
| L7 | **合并重复预测** 避免同质刷分母 | prediction groups | 可能改变 n |
| L8 | **加权评分公式拍板后**作辅信号 | 幅度对错 | 不阻塞命中率主线 |

建议优先验证顺序：**L1 + min_n → L3 核对 → L6 保持 → L5 是否要做**。
