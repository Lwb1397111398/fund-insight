# 前端与接口层

## 职责一句话
`web/index.html` 单页（Vue 3 CDN + axios，无构建步骤）对接 FastAPI 路由，所有 `/api/` 请求都要带访问口令。

## 运作流程
1. 静态页：`src/api/main.py` 注册路由并托管 `web/`（`/`、`/import-data.html` 等）。
2. 鉴权：HTTP 中间件拦截所有 `/api/*`，比对请求头 `X-Access-Password` 与 `ACCESS_PASSWORD`；
   放行非 `/api/` 路径、`OPTIONS` 预检与 `/api/health`。前端把口令存
   `localStorage['access_password']`，收到 401 时清空并弹框重输。
3. 页面结构：顶部统计卡 + 主 Tab（管理博主/帖子/预测/观点、投资建议、TOP 排行、配置）。
   配置弹窗内再分 LLM 配置 / 板块别名 / **板块匹配** / 数据管理。
4. 板块匹配页：`loadSectorMappings()` 拉列表（DB 映射 + 内置映射合并，内置行 `id=None`）、
   行内「AI 匹配 / 编辑 / 审查 / 删除」、`verifyMappingFund()` 单只验证抓取、
   `verifyAllFunds()` 一键验证、`aiBatchMatch('pending'|'gap')` + `pollAiBatch()` 轮询进度，
   结果区展示 `SectorDecision.evidence` 证据链与"替代标的"标记。
5. 长任务：一律"后台状态对象 + 前端轮询"（预测批量验证 `prediction_verify_task`、
   基金更新 `fund_update_task`、AI 批量匹配 `sector_ai_match_task`、导入 `import job`）。
6. 冷启动（Render 免费实例睡着）：取数点分两类 —— `onMounted` 真会打的四笔
   （`/api/stats`、`/api/stats/evidence`、`/api/bloggers`、`/api/predictions/verify-all/status`）
   与"进视图才打"的若干笔（`/api/funds`、`/api/config/sector-mappings`、帖子/预测/观点列表），
   两类都过 `withWakeRetry()` —— 失败且"服务不可用"时先轮
   `/api/health`（免鉴权、真做 `SELECT 1`）等它醒，最长 90 秒，醒了自动重跑一次。
   "服务不可用"= 没答话（超时/断网）**或 502/503/504**；401/403 才是"口令不对"，
   只有这一档允许清 `localStorage['access_password']`；500 原样抛出，既不空等也不删口令。
   多个取数点同时失败共用一个等待（`wakeWait`），提示语与按钮禁用态才不会互相踩。
   子模块要走同一条：`createPredictionManager({ withWakeRetry })` 注入，别在原地自己抄一遍等待。
   任务轮询（帖子分析、观点汇总）是另一条规矩：**只有 404 才丢 `localStorage` 里的任务号**，
   其余失败留着句柄 10 秒后再问、最多 `MAX_POLL_FAILURES` 次（≈15 分钟），停手也不删。

## 入口文件
`web/index.html`（单文件 SPA，很大，改前先定位 section）、`src/api/main.py`、
`src/api/routes/*.py`、`src/api/schemas/*`、`src/api/deps.py`。

## 对外接口与被谁调用
- 前端 → 全部 `/api/*`；`/api/config/*` 见板块匹配与数据管理；`/api/import-database`
  是危险端点（需 `ENABLE_DATABASE_IMPORT=true` + 确认头）。
- 外部：Render Web Service 暴露同一套；APK 是 WebView 壳指向线上站点。

## 上游依赖
FastAPI/Starlette 中间件、Vue 3 CDN、axios、后端各 service。

## 关键数据结构
接口统一返回 `{success, data, message?}`；列表类分页字段 `total/page/size`；
板块映射行字段：`id/sector_name/fund_code/fund_name/reviewed/source/created_at/updated_at`
（+ 本轮新增 `match_source/match_kind/confidence/verified_at/verify_message/is_fetchable/
reviewed_by/owner_locked/evidence`）。

## 已知坑与约束
- **200 + `success:false` 也是一次失败**：这个后端很多拒绝走的是 200 带 `success:false`
  （证据门、清理开关没开、映射冲突、别名重复），只写 `catch` 等于漏掉一半失败。
  第 32 轮 A 数出 16 处 `if (res.data.success)` 没有 else，本轮逐处补：基金列表、板块映射、
  清理预览、三桶预览、配置弹窗 LLM tab、测试数据扫描、基金详情、生成建议。
  推论：**删数据用的按钮不许活过自己的预览** —— 两个清理预览取不到时把 `cleanupEnabled` 关掉。
- **同一个数在两个地方要同一个口径**："待清理"卡片以前显示 `total`（不含连带删除），
  页面里写的是"实际删除 N 行"（含 `cascade_counts`）⇒ 同一个按钮跳过去看到两个数。
  现在卡片直接读 `total_rows_removed` 并把单位写进标签（"待清理（行）"）。
  同理，基金页三个筛选按钮括号里的一直是**本页**（每页 100 只）的行数，与下方"共 242 只"
  不是一个口径 ⇒ 页面上加了一句灰字说明，失败/加载中它们报 `—`。

- **没有构建步骤**：不要引入需要打包的依赖；公共逻辑放 `web/common.js` / `web/common.css`（当前
  `index.html` 里也有大量内联逻辑）。
- 风格要求是"数据工具"：清晰、克制、可扫描；不要 landing page、大渐变、重动画。
- 内置映射行 `id=None`，任何按 id 寻址的新接口都会漏掉问题最集中的一批板块 →
  新接口请像 `ai-match` 一样支持按 `sector_name` 寻址。
- 长请求要设 axios `timeout`（验证全部抓取 180s），否则前端像卡死。
- **取不到数据 ≠ 库里没有，也 ≠ 0**：空状态与统计卡都要区分"真的空""还在取""没取到"。
  博主榜曾把唤醒失败显示成"暂无博主数据"（镜像实测 27 个博主），五个统计卡写的是
  `stats.overall?.X || 0` ⇒ 同一时刻报"0 个博主"；证据体检失败则永远停在"加载中"。
  现在走 `statVal()`（取不到就是 `—`）+ 空状态按 `serviceWaking → loading → 失败 → 真的空` 排序。
  第 6 张"待清理"卡不读 `stats.overall`，用的是 `retentionPreview ? … : '—'` ——
  上一版判据只筛含 `stats.overall` 的卡，对它**结构上不可能响**（第 30 轮两份复评同点）。
- **轮询任务号的清理要分档**：`post-manager.js` / `viewpoint-manager.js` 的 catch 以前无条件
  `clearJob()` / `clearPoll()`（= `localStorage.removeItem`），于是实例唤醒期打开页面会让一个
  正在跑的批量分析**永久失联**，只剩一行 `console.error`。
  第 30 轮我改成"`isServiceDown` 为假就丢句柄"，第 31 轮两份复评指出这仍然错：
  `restoreAnalysisJob()` 在 `onMounted` 里跑、**不等登录门**，而 401/403 归在"为假"那一侧 ⇒
  `ACCESS_PASSWORD` 轮换那天照样丢。现在的规矩是**只有 404 才丢句柄**。
- 一句话里的每个插槽都要有自己的守卫，且**守卫必须是那个字段本身**：
  `v-if="m.realigned.core || m.realigned.kind"` 这种"放宽一点"的写法，对 `core` 为空的
  ETF 升级行照样进这一支，又渲染成"按板块核心词「」"（第 30 轮 A 的变异）。
- **扫文本的前端判据必须配一个能把它打红的变异**（`python scripts/mutation_proof_frontend.py`；
  处数与判据数**不要抄文档**，跑它的 `--list` 看末行）。第 29 轮两份复评各自证明我写的文本判据里有两条**结构上不可能响**：
  一条比对字面 `「」`（渲染出的空格子来自 `{{ }}` 插值，两者永不相等），
  一条用 `<th[^>]*>` 把属性整个吃掉（于是 `not any('title=' in ...)` 恒真）。
  行为类判据优先：`test_the_wake_retry_behaves_the_way_the_page_needs_it` 用 node 执行
  页面里那份源码，喂 401 / 502 / 500 / 断网四种真实形状（另有登录门一条跑七种形状），看它到底等不等、重不重跑。
- **体检自己也要有对照组与互斥闸**（第 32~33 轮）：变异体检开头跑一条 **CONTROL**
  （干净代码上判据必须先全绿），否则"每条变异都红"可能只是子 pytest 起手就失败 —— 那样它会**满分通过**
  而什么都没测。并发跑则会假报一片 GREEN（第 30 轮 B 实测），所以两头抢
  `src/utils/mutation_lock.py` 的 OS 级文件锁：体检抢不到就不启动，`tests/conftest.py` 看到锁被
  持有就 `pytest.exit`。锁随进程退出自动放开，不会留下把仓库锁死的陈旧文件。
- 一句话里多个插槽时，**每个插槽都要有自己的守卫**：`realigned` 的 `core`/`from_code`
  对 ETF 升级行是空的，无条件插值就渲染成"按板块核心词「」"（第 26 轮任务 #26）。
- 本机控制台/浏览器中文正常，但**跨进程输出**要显式 UTF-8（`subprocess(text=True)` 默认 GBK，
  中文用户名路径会让 stdout 变 None，已踩过）。
- `src/api/main.py` 里 `ACCESS_PASSWORD` 的默认值曾是硬编码真实口令，已列为推送 GitHub
  前的硬性检查项（改为无默认值 + fail-closed）。
