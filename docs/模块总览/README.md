# 模块总览

本目录是 Fund Insight 的"人话说明书"：不读代码也能知道每块功能怎么运作、改哪里会影响谁。
每个文件必含：职责一句话 / 运作流程 / 入口文件 / 对外接口与被谁调用 / 上游依赖 / 关键数据结构 / 已知坑 / 最后更新。
**改代码前先读对应总览；改完立刻更新，"最后更新"必须写日期 + 改动摘要。**

| 模块 | 职责一句话 |
| --- | --- |
| [板块与基金匹配](板块与基金匹配.md) | 决定"某个板块该用哪只基金来验证观点"，并给出可复核的证据链 |
| [基金数据抓取与验证](基金数据抓取与验证.md) | 从天天基金/东财取净值与历史，判断某只基金是否真实可抓 |
| [帖子录入与LLM分析](帖子录入与LLM分析.md) | 把博主帖子交给 LLM，抽成预测/观点并落库 |
| [预测验证与准确率统计](预测验证与准确率统计.md) | 用净值判断预测对不对，算博主准确率与等级 |
| [前端与接口层](前端与接口层.md) | FastAPI 路由、访问口令中间件与单页前端的对接方式 |

> 另有 `src/*/MODULE_RECORD.md` 是目录级的细粒度记录，本目录是跨模块的功能视角。
